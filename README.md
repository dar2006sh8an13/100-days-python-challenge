# 100 Days of Python Challenge 🐍

A structured learning challenge for building Python programming skills through consistent daily practice.

## Challenge Approach

Work through one focused exercise or concept each day. Keep solutions small, explain the idea being practiced, and revisit earlier topics to strengthen understanding.

## Suggested Learning Path

| Stage | Topics |
|---|---|
| Days 1–10 | Setup, syntax, variables, data types, input/output |
| Days 11–20 | Conditions, loops, functions |
| Days 21–30 | Strings, lists, tuples, sets, dictionaries |
| Days 31–40 | Files, exceptions, modules, packages |
| Days 41–50 | Object-oriented programming |
| Days 51–60 | Algorithms and problem solving |
| Days 61–70 | APIs, JSON, and automation |
| Days 71–80 | Data analysis and visualization |
| Days 81–90 | Small practical applications |
| Days 91–100 | Final project, testing, and documentation |

This is a suggested progression; the actual exercises in the repository define the current challenge content.

## Requirements

- Python 3.10 or later.
- A code editor such as VS Code.
- Git for version control.

## Getting Started

```bash
git clone https://github.com/dar2006sh8an13/100-days-python-challenge.git
cd 100-days-python-challenge
python --version
```

Run an exercise using the relevant filename:

```bash
python day-01.py
```

Adjust the filename to match the files in the repository.

## Daily Progress

Track each completed day in the source folder or a personal checklist. For every exercise, record the problem, approach, key concept, and sample output.

## Contributing

If this is a personal learning log, keep solutions authentic and explain your own approach. For external contributions, open an issue or pull request with context and test steps.
